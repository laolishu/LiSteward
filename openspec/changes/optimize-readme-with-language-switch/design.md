# 设计文档：README 优化与语言切换

**变更ID**: optimize-readme-with-language-switch

**日期**: 2025-12-28

## 概述

本设计文档详细规划 README 优化和语言切换功能的实现细节。

## 架构设计

### 1. 语言切换机制

#### 方案选择：简单链接式

选择在文档顶部添加清晰的语言切换链接，原因：

1. **简单性**：无需修改代码或添加动态功能
2. **可维护性**：每个文件独立维护自己的链接
3. **用户友好**：一键点击即可切换语言
4. **GitHub 兼容**：支持所有 GitHub 仓库页面

#### 实现形式

在两个 README 顶部添加统一的语言切换提示框：

```markdown
# README 标题前

**[English](README.md) | [中文](README_CN.md)**

---

# 标题部分...
```

### 2. 文档结构优化

#### 一级标题层次

```
- 语言切换（顶部）

  - 小节：Hosts 管理
```

#### 内容优化策略

1. **概述部分**
   - 保留现有简洁的概述
   - 添加一句话说明两个核心模块

2. **核心特性部分（新增或扩展）**
   - Hosts 管理功能清单
   - NVM 版本管理功能清单
   - 每个功能 1-2 行简洁描述

3. **快速开始**
   - 明确分为"获取应用"和"开始使用"两部分
   - 添加截图或功能概览（可选）

4. **构建说明**
   - 优化格式，分清开发环境和发布环境
   - 添加必要的前置条件说明（如 Go、Node.js 版本）

### 3. Hosts 管理功能描述

#### 功能点

1. **配置文件管理**
   - 可视化编辑 hosts 文件，无需手动打开文本编辑器
   - 支持多个配置方案，快速在不同配置间切换
   
2. **备份与恢复**
   - 自动备份编辑历史
   - 一键恢复到任何历史版本
   
3. **导入与导出**
   - 支持导入现有 hosts 配置
   - 支持导出当前配置供其他机器使用
   
4. **高级特性**
   - 条目启用/禁用开关（无需删除即可禁用规则）
   - 快速搜索和过滤功能
   - 支持多 IP 和备用 IP 地址

#### 使用场景

- 前端开发：管理本地域名映射和测试环境配置
- 网络管理：快速切换不同的网络配置
- 项目管理：为每个项目维护独立的 hosts 配置

### 4. NVM 版本管理功能描述

#### 功能点

1. **版本检测与显示**
   - 自动检测系统安装的 Node.js 版本
   - 清晰展示当前激活的版本
   
2. **快速版本切换**
   - 一键切换到已安装的任意 Node.js 版本
   - 立即生效，无需重启应用或终端
   
3. **版本安装**
   - 快速打开命令行查看可用版本列表
   - 一键启动安装流程
   
4. **环境管理**
   - 支持不同的 NVM 环境配置（如 nvm-windows）
   - 自动识别系统环境变量设置

#### 使用场景

- 多项目开发：不同项目可能要求不同的 Node.js 版本
- 版本兼容性测试：快速测试代码在不同 Node.js 版本上的表现
- 版本升级管理：平滑地从旧版本迁移到新版本

### 5. 中英文版本同步机制

#### 对等性原则

- 两个版本的结构和逻辑完全相同
- 内容表达等价（不是逐字翻译，而是意思对等）
- 所有链接在两个版本中指向相应的文档

#### 维护方式

1. 在 README.md 中制定结构和内容（英文为主）
2. 在 README_CN.md 中保持同样的结构（中文翻译）
3. 两个文件在同一次更新中一起修改，保持同步

### 7. 视觉和排版考虑
