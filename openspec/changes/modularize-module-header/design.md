# 设计文档：ModuleHeader 组件

## 设计目标

创建一个统一、可复用的模块页头组件，满足以下目标：

1. **消除重复代码**: 统一各模块的页头实现
2. **提高可维护性**: 集中管理样式和结构
3. **保持一致性**: 确保所有模块的视觉效果一致
4. **灵活扩展**: 支持不同的页头变体

## 架构设计

### 组件结构

```
ModuleHeader
├── Title (主标题)
├── SubTitle (副标题，可选)
├── Hint (提示信息容器)
│   ├── Success Hint
│   ├── Error Hint
│   ├── Warning Hint
│   └── Info Hint
└── Actions (操作区，可选)
```

### 组件 Props

| 属性 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `title` | String | 是 | 模块标题，支持 i18n key |
| `subtitle` | String | 否 | 模块副标题，支持 i18n key |
| `hint` | Object | 否 | 提示信息对象 |
| `hint.type` | String | 否 | 提示类型：success/error/warning/info |
| `hint.message` | String | 否 | 提示消息文本 |
| `showHint` | Boolean | 否 | 是否显示提示，默认 true |

### 样式方案

#### 整体布局

- **高度**: 页头区域固定高度 80-100px
- **背景**: 白色背景 (#ffffff)
- **边框**: 下边框 1px #e1e4e8
- **内边距**: 上下 24px，左右根据容器调整

- **字体大小**: 24px

### 交互设计

1. **提示自动关闭**: 错误/成功提示显示 5 秒后自动消失
2. **关闭按钮**: 提示框右侧包含关闭按钮，允许用户手动关闭
3. **转场效果**: 使用 `transition` 实现提示框的淡入淡出效果

## 实施细节

### 国际化集成

组件支持 i18n key，但不直接处理翻译：
- `title` 和 `subtitle` 可以是中文字符串或 i18n key
- 父组件负责通过 `$t()` 进行翻译并传入

### 消息提示处理

1. **来源**: 提示信息可来自父组件的响应式状态
2. **更新**: 父组件通过修改 `hint` 属性更新提示
3. **清除**: 用户点击关闭按钮或自动超时后清除提示

### 组件分离

考虑创建 `ModuleHeaderHint` 子组件：
- 独立管理提示的显示/隐藏逻辑
- 支持自动超时功能
- 简化 ModuleHeader 的代码复杂度

## 样式继承

### Tailwind CSS vs 内联样式

采用混合方案：
- **容器布局**: 使用 Tailwind 类 (flex, padding, border 等)
- **细微调整**: 使用内联样式或 scoped style
- **响应式**: 考虑添加响应式支持（如移动端）

## 向后兼容性

- 旧组件逐步替换，不影响现有功能
- Settings.vue 中的消息提示继续支持，新组件不破坏既有功能

## 扩展点

1. **自定义操作按钮**: 通过 slot 支持在页头右侧添加操作按钮
2. **主题切换**: 预留主题定制接口
3. **无障碍**: 支持 aria-label 等辅助属性

## 依赖关系

- Vue 3 (Composition API)
- vue-i18n
- CSS 样式（无额外依赖）
