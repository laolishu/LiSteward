# 任务列表：模块页头组件化

## 总体目标

完成 ModuleHeader 组件的设计与实现，并将其集成到 NodeManager、Settings 和 HostsManager 中，统一各模块的页头样式和交互。

---

## 阶段 1: 组件开发 (可并行)

### 任务 1.1: 创建 ModuleHeader 组件基础结构

**依赖**: 无

**验证方式**:
- 组件文件 `frontend/src/components/ModuleHeader.vue` 存在
- 组件支持 `title` prop 并正确渲染 h1 标签
- 组件支持 `subtitle` prop 并在标题下方显示
- 页头容器样式符合设计（白色背景、下边框、padding）

**交付物**: `frontend/src/components/ModuleHeader.vue`（包含基础 title 和 subtitle）

---

### 任务 1.2: 实现 ModuleHeader 提示框功能

**依赖**: 任务 1.1 完成

**验证方式**:
- 组件支持 `hint` prop，结构为 `{ type, message }`
- Success 提示框样式正确（背景、文字、边框）
- Error 提示框样式正确
- Warning 和 Info 提示框样式正确
- 提示框包含关闭按钮，点击可隐藏
- 成功提示 5 秒后自动消退（通过 setTimeout）
- 错误提示不自动消退

**交付物**: ModuleHeader.vue 更新（添加提示框逻辑和样式）

---

### 任务 1.3: 添加提示框转场动画

**依赖**: 任务 1.2 完成

**验证方式**:
- 提示框显示/隐藏时有淡入淡出效果
- 转场时间为 0.3s 左右
- 动画流畅，无卡顿

**交付物**: ModuleHeader.vue 更新（CSS transition）

---

### 任务 1.4: 添加国际化和可访问性支持

**依赖**: 任务 1.1 完成

**验证方式**:
- 标题使用 `<h1>` 或 `<h2>` 标签
- 关闭按钮有 `aria-label` 属性
- 提示框有 `role="alert"` 或 `role="status"`
- 图标有 `alt` 属性

**交付物**: ModuleHeader.vue 更新（语义化标签和 ARIA 属性）

---
