# 任务列表：HostsManager 模块 ModuleHeader 集成

## 总体目标

为 HostsManager 模块添加 ModuleHeader 组件，将现有的消息提示系统集成到统一的页头组件中，保持布局不变，提升用户体验一致性。

---

## 前置条件

- ✅ modularize-module-header 提案已实施完成
- ✅ ModuleHeader 组件 (`frontend/src/components/ModuleHeader.vue`) 已创建
- 无其他阻断条件

---

## 任务 1: HostsManager 消息数据重构

**依赖**: 无（可在修改前进行）

**验证方式**:
- 新增 `messageHint` ref，初始值为 `null`
- 新增 `showMessage(text, type, duration)` 方法
- 方法能正确处理成功/错误提示的生命周期管理
- 成功提示在指定时长后自动清除
- 错误提示可手动关闭

**交付物**: HostsManager.vue 数据和方法更新

**预计时间**: 0.5-1 小时
