# Hosts 文件管理规范

## 目的

增强现有的 Hosts 文件管理系统，支持多 IP 场景和更灵活的条目管理。通过支持备选 IP 和结构化描述，提升在多环境配置中的效率。

## 修改需求

### 需求：Hosts 文件读取增强

系统必须能够读取和解析扩展的 Hosts 文件格式，同时保持对现有格式的向后兼容。

#### 场景：解析扩展格式的条目

- **当** Hosts 文件包含行 `127.0.0.1 www.example.com # 192.168.1.100#生产环境`
- **那么** 解析为：
  - IP=`127.0.0.1`
  - Domain=`www.example.com`
  - AlternateIP=`192.168.1.100`
  - Description=`生产环境`
  - Enabled=`true`

#### 场景：解析仅有备选 IP 的条目

- **当** Hosts 文件包含行 `127.0.0.1 api.dev.local # 10.0.0.5#`
- **那么** 解析为：
  - IP=`127.0.0.1`
  - Domain=`api.dev.local`
  - AlternateIP=`10.0.0.5`
  - Description=`` (空)
  - Enabled=`true`

#### 场景：向后兼容旧格式

- **当** Hosts 文件包含行 `127.0.0.1 legacy.example.com # 这是旧注释`
- **那么** 解析为：
  - IP=`127.0.0.1`
  - Domain=`legacy.example.com`
  - Comment=`这是旧注释`
  - AlternateIP=`` (空)
  - Description=`` (空)
  - Enabled=`true`

---

### 需求：Hosts 文件写入增强

系统必须能够将扩展格式的条目正确写入 Hosts 文件，同时保持原有的 Hosts 文件格式兼容性。

#### 场景：生成扩展格式条目

- **当** 条目为：IP=`127.0.0.1`, Domain=`dev.example.com`, AlternateIP=`192.168.1.100`, Description=`开发环境`, Enabled=`true`
- **那么** 生成行：`127.0.0.1    dev.example.com    # 192.168.1.100#开发环境`

#### 场景：生成禁用的扩展格式条目

- **当** 条目为：IP=`172.16.0.5`, Domain=`old.server.com`, AlternateIP=`172.16.0.6`, Description=`旧服务器备选`, Enabled=`false`
- **那么** 生成行：`# 172.16.0.5    old.server.com    # 172.16.0.6#旧服务器备选`

#### 场景：生成旧格式条目（保持兼容）

- **当** 条目为：IP=`127.0.0.1`, Domain=`legacy.local`, Comment=`旧注释`, AlternateIP=`` (空), Description=`` (空), Enabled=`true`
- **那么** 生成行：`127.0.0.1    legacy.local    # 旧注释`

---

### 需求：交换 IP 功能

系统必须提供快速交换主 IP 和备选 IP 的功能，便于在多环境间切换。

#### 场景：成功交换 IP

- **当** 用户点击某条目的"交换"按钮
  - 条目原始状态：IP=`127.0.0.1`, AlternateIP=`192.168.1.100`
- **那么** 条目更新为：IP=`192.168.1.100`, AlternateIP=`127.0.0.1`
- **并且** UI 立即反映变更
- **并且** 标记为已修改，等待"应用"确认

#### 场景：交换后保留描述

- **当** 交换 IP 时，原始条目：IP=`127.0.0.1`, AlternateIP=`192.168.1.100`, Description=`开发环境`
- **那么** 交换后：IP=`192.168.1.100`, AlternateIP=`127.0.0.1`, Description=`开发环境`
- **并且** 描述保持不变

---

### 需求：条目编辑增强

系统必须支持在编辑界面中修改备选 IP 和描述信息。

#### 场景：编辑条目的备选 IP

- **当** 用户打开编辑弹窗编辑条目
- **那么** 显示字段：主 IP、域名、备选 IP(新增)、描述(新增)、备注
- **并且** 所有字段预填充当前值
- **并且** 用户可修改任何字段

#### 场景：备选 IP 格式验证

- **当** 用户在"备选 IP"输入框中输入值
- **那么** 系统验证其为有效的 IPv4/IPv6 地址或允许为空
- **并且** 如果格式无效，显示错误提示

---

### 需求：前端表格显示增强

系统必须增强表格以展示新的条目信息，保持清晰和可用性。

#### 场景：表格显示新列

- **当** 打开 Hosts 管理界面
- **那么** 表格包含列：序号、状态、域名、主 IP、备选 IP(新增)、描述(新增)、操作

#### 场景：表格中显示空值

- **当** 条目的备选 IP 或描述为空
- **那么** 显示为空白或占位符"-"
- **并且** 不显示"null"文本

#### 场景：操作列包含交换功能

- **当** 在表格操作列中
- **那么** 显示按钮：✏️ 编辑、⇅ 交换(新增)、🗑️ 删除
- **并且** 交换按钮仅在备选 IP 不为空时启用
