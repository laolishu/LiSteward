## 🎨 设计亮点

### 1. 侧栏拖动功能
```vue
<!-- 可拖动分隔符 -->
<div class="divider" @mousedown="startDragging"></div>

<!-- 宽度限制与动画 -->
<div class="sidebar-wrapper" :style="{ width: sidebarWidth + 'px' }">
  <!-- 侧栏内容 -->
</div>
```
- 宽度范围: 200px ~ 400px
- 拖动时实时反馈（颜色变化）
- 自动保存到 localStorage

### 2. 侧栏折叠动画
```javascript
toggleSidebar() {
  if (sidebarCollapsed.value) {
    sidebarWidth.value = 60  // 仅显示图标
  } else {
    sidebarWidth.value = 300 // 恢复默认
  }
}
```
- 平滑过渡（0.3s）
- 保留菜单图标可见

### 3. 同步状态指示器
```vue
<div class="sync-status" :class="syncStatusClass">
  {{ syncStatusText }}
</div>
```
状态显示:
- 🟡 正在同步... (动画脉冲)
- ✅ 已同步 (绿色)
- ❌ 同步失败 (红色)

### 4. 响应式布局
```css
@media (max-width: 1400px) { /* 大屏 */ }
@media (max-width: 1000px) { /* 中屏 */ }
@media (max-width: 800px)  { /* 小屏 */ }
```

## 💡 设计决策理由

### 为什么选择 MainLayout.vue 而不是增强 App.vue？
| 方案 | 优点 | 缺点 |
|------|------|------|
| 创建 MainLayout.vue | ✅ 职责清晰 ✅ 易于维护 ✅ 可复用 | ➖ 多一个文件 |
| 增强 App.vue | ✅ 文件少 | ❌ 混淆职责 ❌ 难维护 |

**决策**: 创建 MainLayout.vue

### 为什么使用 localStorage 而不是 Vuex/Pinia？
状态简单（仅侧栏宽度），localStorage 足够，避免过度设计

### 为什么限制侧栏宽度在 200-400px？
- 200px: 最小显示内容
- 400px: 超大屏幕上合理范围
- 300px: 黄金分割比例
