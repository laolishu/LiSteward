## 📐 设计理念

### 为什么选择深海蓝?
1. **护眼** - 深色背景减少眼睛疲劳
2. **专业** - 深蓝色显得更高端、专业
3. **现代** - 符合当代 UI 设计趋势
4. **统一** - 与绿色品牌色搭配协调

### 为什么用透明绿而不是实色?
1. **精细** - 透明效果更现代、更精致
2. **灵活** - 可以与任何背景色组合
3. **和谐** - 避免颜色突兀，融合度高
4. **视觉** - 提供微妙但清晰的反馈

### 为什么统一使用 #34D399?
1. **品牌** - 老李树绿是项目品牌色
2. **识别** - 用户立即识别品牌
3. **一致** - 减少颜色复杂度
4. **可维护** - 单一品牌色便于修改
