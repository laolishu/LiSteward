# 规范：赞赏功能

## 新增需求

### 需求：显示微信赞赏二维码

设置页面**必须**在"关于"部分显示微信赞赏二维码，允许用户通过扫描二维码来支持开发者。

#### 场景：用户查看赞赏二维码

用户在设置页面的"关于"部分**应该**能看到：
- 赞赏标题或提示文本
- 微信赞赏二维码图片
- 扫描二维码的说明文字

示例显示：
```
微信赞赏
扫描下方二维码，支持开发者继续维护此项目

[200×200 二维码图片]
```

#### 场景：二维码来自配置

二维码图片路径**必须**从配置文件中读取（`AppConfig.SponsorQrCode` 字段）。

支持的来源：
- 本地文件路径（相对于应用根目录）
- 数据 URL
- 远程 URL

如果配置中没有提供二维码，则**禁止**显示此部分。

#### 场景：响应式二维码显示

在不同屏幕大小上：
- 桌面版：二维码**必须**显示为 200×200 像素
- 移动设备（未来）：二维码**应该**显示为 150×150 像素

### 需求：赞赏信息国际化

赞赏部分的所有文本**必须**支持多语言。

#### 场景：用户在不同语言下查看赞赏

- 中文用户**必须**看到中文提示
- 英文用户**必须**看到英文提示

所有翻译文本**必须**存储在 i18n 配置中。

### 需求：赞赏二维码资源管理

应用**必须**支持集成二维码图片资源。

#### 场景：打包应用时包含二维码

打包过程中**必须**包含：
- 二维码图片文件
- 正确的文件路径配置

建议位置：`./data/assets/wechat-qr.png`

#### 场景：保存和后续更新二维码

如果需要更新二维码：
1. 替换资源文件
2. **禁止**修改应用代码
3. 配置文件中的 `SponsorQrCode` 路径**无需**变更
