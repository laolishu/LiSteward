# 变更：添加关于页面（版本信息和赞赏二维码）

## 为什么

LiSteward 应用需要向用户展示应用的基本信息和支持方式，当前的实现存在以下问题：

- **应用信息不透明**：用户无法在应用内查看当前运行的版本号
- **官方渠道不清晰**：用户不知道如何访问官方网站或获取更新信息
- **开发者支持缺失**：无法展示对开发者的支持方式（赞赏二维码）
- **用户体验不完整**：标准应用都包含"关于"页面，本应用缺少此功能

## 变更内容

### 核心功能

#### 1. 版本信息展示

在设置页面添加一个"关于"部分，包含：

- **应用名称**：显示产品名称（中文名"李管家"和英文名"LiSteward"）
- **版本号**：从 `config/app.json` 的 `version` 字段读取并显示
- **官方网址**：显示可点击的链接指向官方网站
- **作者信息**：显示作者名称和邮箱（可选）

示例布局：
```
关于李管家
李管家 (LiSteward) v0.1.0

官方网站：https://example.com
作者：lfz (lfzxs@qq.com)
```

#### 2. 微信赞赏二维码

在"关于"部分添加：

- **赞赏提示**：提示用户可以通过微信扫描二维码进行赞赏
- **二维码显示**：显示微信赞赏二维码图片（通过前端资源或数据 URL）
- **可选的点击互动**：允许用户点击二维码放大查看或保存

#### 3. 配置扩展

扩展 `config/app.json` 以支持：

- **官方网址**：`website` 字段
- **赞赏二维码 URL**：`sponsorQrCode` 字段（或存储位置）

更新后的配置示例：
```json
{
  "version": "0.1.0",
  "website": "https://example.com",
  "sponsorQrCode": "./data/assets/wechat-sponsor-qr.png",
  ...
}
```

## 验收标准

- [x] 版本信息**必须**正确从配置文件读取并显示
- [x] 官方网址**必须**可点击并打开浏览器
- [x] 赞赏二维码**必须**在设置页面正确显示
- [x] 配置文件**必须**扩展完整（website、sponsorQrCode）
- [x] **必须**支持国际化（中英文）
- [x] **必须**响应式设计，适配不同屏幕尺寸
- [x] 二维码图片资源**必须**正确集成
- [x] 前后端编译通过，测试覆盖

## 相关变更

- 与 `add-user-config-system` 变更无冲突（配置目录结构可兼容）
- 前端依赖：Vue 3、vue-i18n（已有）
- 后端依赖：无（只读配置文件）
