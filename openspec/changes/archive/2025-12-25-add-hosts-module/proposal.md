# 变更：添加 Hosts 文件管理模块

## 为什么

LiSteward 作为开发环境配置工具，需要提供便捷的 Hosts 文件管理功能。开发者经常需要：
- 修改 Hosts 文件来指向开发/测试环境
- 在多个配置方案之间快速切换（开发、测试、生产）
- 备份 Hosts 文件以防误操作导致系统网络异常
- 需要 Administrator 权限进行文件操作

当前缺少统一的 Hosts 管理工具，开发者需要手动编辑系统文件，容易出错且效率低下。

## 变更内容

### 核心功能
- **Hosts 文件读写**：读取和修改 Windows Hosts 文件（`C:\Windows\System32\drivers\etc\hosts`）
- **方案管理**：创建、保存、加载多个 Hosts 配置方案（开发环境、测试环境等）
- **备份恢复**：自动备份当前 Hosts 文件，支持恢复到历史版本
- **条目管理**：添加、删除、启用/禁用 Hosts 条目（通过注释符 `#`）
- **验证功能**：验证 IP 地址和域名格式，防止配置错误

### 技术实现
- 后端：Go 服务实现文件读写、备份管理
- 前端：Vue3 组件展示和操作 Hosts 条目
- 权限：利用 Administrator 权限进行系统文件操作
- 存储：方案和备份存储在应用数据目录

### 用户体验
- 可视化编辑界面，无需手动编辑文本
- 一键切换方案
- 自动备份机制，安全可靠

## 影响

### 受影响规范
- **新增**：`specs/hosts-management/` - 全新功能模块

### 受影响代码
- 后端新增：
  - `internal/hosts/` 包 - Hosts 文件操作服务（已移动至 `internal` 目录，遵循 Go 内部包规范）
  - `app.go` - 添加 Hosts 模块的 Wails 绑定方法
- 前端新增：
  - `views/HostsManager.vue` - Hosts 管理界面
  - 路由配置更新

### 依赖变更
- 无新的外部依赖
- 使用 Go 标准库进行文件操作
- 使用 Wails 运行时进行对话框操作（备份/恢复确认）

### 风险评估
- **低风险**：
  - 文件操作限制在 Hosts 文件
  - 自动备份机制防止数据丢失
  - 格式验证防止配置错误
- **需注意**：
  - 必须正确处理 Administrator 权限
  - 并发写入保护（虽然单用户应用，但需考虑外部修改）
