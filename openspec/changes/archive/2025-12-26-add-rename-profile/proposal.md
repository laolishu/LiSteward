# 变更：配置方案重命名功能

## 为什么
当前用户无法修改已保存的配置方案名称。如果方案名称不合适或需要更新，用户只能删除旧方案并重新创建新方案，这样会导致方案数据丢失的风险，且操作繁琐。

## 变更内容
- 在每个方案卡片上添加"编辑"或"重命名"按钮
- 点击按钮后显示输入对话框，允许用户输入新的方案名称
- 后端添加方案重命名接口，处理重名检查和文件操作
- 成功重命名后刷新方案列表，更新 UI 显示

## 影响
- 受影响规范：[hosts-management](../specs/hosts-management/spec.md)
- 受影响代码：
  - 前端：`frontend/src/views/HostsManager.vue`（添加重命名按钮和对话框）
  - 后端：`internal/hosts/service.go`（添加 RenameProfile 方法）、`app.go`（暴露方法）

## 相关设计决策
- **交互方式**：在方案卡片右侧添加编辑图标，避免误触
- **冲突处理**：如果新名称已存在，显示确认是否覆盖的对话框
- **数据安全**：重命名前后验证文件完整性，失败时保留原文件
