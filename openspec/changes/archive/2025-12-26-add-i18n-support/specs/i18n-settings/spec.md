# 规范增量：i18n-settings（国际化设置界面）

## 功能描述

在应用的设置模块中实现语言选择和切换功能，允许用户自主选择应用界面语言。

## 前置需求

- 依赖 i18n-core 规范完成
- 确保 vue-i18n 已初始化
- 确保翻译资源已加载

## 新增需求

### 需求：创建 Settings 视图组件
应用必须创建设置界面，展示应用设置选项。

#### 场景：用户打开设置
用户点击主菜单中的"设置"项，必须打开设置视图。

### 需求：在 Settings 中添加语言选择控件
应用必须提供下拉菜单或单选按钮让用户选择语言。

#### 场景：选择中文
用户在设置中选择"中文 (Chinese)"，应用界面必须切换为中文。

#### 场景：选择英文
用户在设置中选择"English"，应用界面必须切换为英文。

### 需求：实现实时语言切换
应用必须在用户改变语言选择后立即更新界面，无需重启应用。

#### 场景：动态切换
用户从中文切换到英文，整个界面（菜单、按钮、表格、对话框等）必须立即以英文显示。

#### 场景：反馈提示
切换语言后必须显示成功提示信息（"界面语言已切换"）。

### 需求：同步保存用户语言偏好
用户选择语言后，该选择必须被保存到后端配置和前端本地存储。

#### 场景：重启应用后保留选择
用户选择英文并关闭应用，再次打开时应用必须仍然显示英文界面。

### 需求：获取当前语言状态
应用必须在设置界面中显示当前选中的语言。

#### 场景：显示当前语言
用户打开设置时，语言下拉菜单必须显示当前选择的语言。

## 修改需求

### 需求：主菜单中的设置项
应用必须确保"设置"菜单项已在主菜单中展示。

#### 场景：菜单导航
用户必须能够点击主菜单中的"设置"项进入设置页面。

### 需求：路由配置支持设置页面
应用必须添加设置页面的路由，使其可被正确访问。

#### 场景：路由导航
前端路由配置必须支持导航到 settings 页面。

## 验收标准

- [ ] Settings 视图成功创建并可访问
- [ ] 语言选择下拉菜单在界面上正确显示
- [ ] 当前语言状态在菜单中准确显示
- [ ] 用户切换语言后，整个界面立即更新
- [ ] 所有界面文本都使用新选择的语言显示
- [ ] 语言选择被正确保存到后端配置
- [ ] 应用重启后保留用户的语言选择
- [ ] localStorage 中正确保存语言偏好
- [ ] 切换成功后显示确认提示
- [ ] 菜单导航正确指向设置页面
