## 提案概览

**变更 ID**: `add-i18n-support`

**目标**: 为 LiSteward 应用添加完整的国际化（i18n）支持，支持中文和英文两种语言，支持系统语言自动检测，以及在设置模块中进行语言切换。

## 实施方式

### 语言检测优先级
```
用户已保存的语言 > Windows 系统语言 > 默认中文 (zh-CN)
```

### 前端语言切换流程
```
用户选择 → 调用后端保存 → 更新 localStorage → 切换 i18n 语言 → UI 实时刷新
```

### 技术栈
- **前端**：Vue 3 + Composition API + vue-i18n
- **后端**：Go + Windows API + 配置系统
- **通信**：Wails RPC 绑定
