## 技术亮点

### 后端实现

✅ **Windows 系统语言检测**
- 使用 Windows API GetLocaleInfoA
- 获取 LOCALE_SNAME 返回 zh-CN/en-US 格式
- 自动降级处理，异常时返回默认中文

✅ **配置持久化**
- 在 AppConfig 中添加 Language 字段
- 支持 JSON 序列化/反序列化
- 优先级逻辑：用户设置 > 系统语言 > 默认中文

✅ **Wails 绑定**
- GetSystemLanguage()：获取系统语言
- GetUserLanguagePreference()：获取用户偏好
- SetUserLanguagePreference()：保存用户选择

### 前端实现

✅ **vue-i18n 集成**
- Composition API 风格配置
- 支持动态语言切换
- 自动加载翻译资源

✅ **完整翻译覆盖**
- 中文翻译：完整的用户界面文本
- 英文翻译：对应的英文版本
- 翻译 keys 结构化组织

✅ **Settings 界面**
- 美观的设置面板设计
- 语言下拉菜单

## 系统流程

### 应用启动流程

```
1. 应用启动 (startup)
   ↓
2. 读取配置文件 config/app.json
   ↓
3. 检查 config.Language 字段
   ├─ 如果设置 → 使用该语言
   └─ 如果为空 → 检测系统语言
   ↓
4. 前端 i18n 初始化
   ├─ 读取 localStorage 中的语言偏好
   └─ 加载对应的翻译资源
   ↓
5. 渲染界面（使用翻译文本）
```

### 用户切换语言流程

```
1. 用户打开设置 → Settings.vue
   ↓
2. 用户在下拉菜单选择语言
   ↓
3. changeLanguage() 被触发
   ├─ 调用后端 SetUserLanguagePreference(lang)
   ├─ 保存到 localStorage
   └─ 切换 i18n 的 locale.value
   ↓
4. 界面实时更新（所有文本切换）
   ↓
5. 显示成功提示 "界面语言已切换"
   ↓
6. 应用重启时，该语言偏好被保留
```
