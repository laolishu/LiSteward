# 提案：添加系统托盘与全局快捷键功能 (add-system-tray)

## 为什么

用户经常需要长时间保持应用运行以管理 Hosts 配置。当前每次启动应用都需要手动打开窗口，降低了工作效率。通过系统托盘集成，用户可以将应用最小化到托盘，并通过全局快捷键快速唤醒应用窗口，提升应用的易用性和可用性。

## 变更内容

本变更为桌面应用增加了以下功能：

1. **系统托盘集成**：应用可以最小化到 Windows 系统托盘，用户可从托盘图标恢复窗口。
2. **全局快捷键支持**：注册全局热键（如 Ctrl+Alt+L），允许用户在任何时刻通过快捷键唤醒或隐藏应用窗口。
3. **托盘菜单**：在托盘菜单中提供"显示"、"隐藏"、"退出"等操作选项。
4. **用户配置持久化**：将快捷键与托盘设置保存在用户配置中，下次启动时恢复用户偏好。
5. **跨平台支持**（预留）：为 macOS 与 Linux 提供相应的托盘与快捷键实现的设计预留。

## 目标

- 在 Windows 平台上实现系统托盘最小化功能，允许用户在托盘中快速访问应用。
- 实现全局快捷键注册与监听，支持用户在应用外唤醒应用窗口。
- 使用 Wails v2 原生托盘 API（`runtime.WindowSetAlwaysOnTop`, `runtime.WindowHide`, `runtime.WindowShow` 等）与系统托盘支持。
- 为将来跨平台扩展保留清晰的抽象接口与设计。

## 约束

- 快捷键为用户可配置（在设置中提供选项），默认为 Ctrl+Alt+L，但用户可自定义。
- 托盘菜单项需国际化支持（中文与英文）。
- 不自动启用（默认关闭），用户可在设置中启用/禁用托盘最小化功能与快捷键。
- 快捷键仅在托盘功能启用时生效。

## 验收标准（高层）

- 用户可在 Settings 页启用/禁用"最小化到托盘"功能。
- 启用后，关闭按钮（X）将应用最小化到托盘而非退出。
- 用户可通过托盘图标菜单"显示"选项恢复窗口；点击托盘图标也能快速切换窗口显示/隐藏。
- 用户可配置全局快捷键（默认 Ctrl+Alt+L），在任何时刻按下时唤醒或隐藏应用窗口。
- 配置在用户 config 文件中持久化，应用重启后恢复。
